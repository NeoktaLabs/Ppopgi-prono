# Oddzz

Oddzz is a free, ad-free World Cup 2026 prediction app for friends, colleagues, and private leagues.

Players predict scores, use two group-stage x5 bonuses, follow live leaderboards, and compare themselves with OddzzAI.

Built with React, Vite, Cloudflare Workers, D1, Resend, API-Football, and OpenAI.

```bash
npm install
npm run dev
```
